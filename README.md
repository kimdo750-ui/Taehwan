# 🌾 영농사업화 플랫폼

**한농대 졸업 후 6년 의무영농을 위한 완벽한 사업화 의사결정 도구**

> "내년에 뭘 심을지" 결정하고, "얼마가 필요한지" 계산하고, "얼마를 벌 수 있는지" 예측하는 플랫폼

---

## 🚀 빠른 시작

### 웹에서 바로 사용
- **링크**: https://kimdo750-ui.github.io/Taehwan/
- 또는: https://taehwan.vercel.app/ (곧 배포)

### 로컬에서 사용
```bash
# 리포지토리 클론
git clone https://github.com/kimdo750-ui/Taehwan.git
cd Taehwan

# index.html을 웹브라우저에서 열기
# (인터넷 연결 필요 없음 - 오프라인 지원)
```

### 모바일 앱으로 사용
1. 웹페이지 열기
2. 공유 → "홈 화면에 추가"
3. 앱처럼 사용 (오프라인 가능)

---

## 📋 플랫폼 구조

```
🎯 메인 대시보드 (index.html)
│
├─ 🔍 1단계: 진단 (3개 도구)
│  ├─ 영농형태 진단 (영농형 vs 준비형)
│  ├─ 작물 진입 판단 (지금 심을지 말지)
│  └─ 채널별 마진 분석 (도매 vs 직판)
│
├─ 💼 2단계: 계획 (3개 도구)
│  ├─ 초기 투입비용 계산
│  ├─ 수익 시뮬레이션
│  └─ 사업계획서 자동생성
│
├─ 🏛️ 3단계: 지원 (3개 도구)
│  ├─ 정부 지원금 안내
│  ├─ 위험 관리 체크리스트
│  └─ 지역별 기술센터/농협 연락처
│
└─ 📊 데이터 자료 (KREI·KAMIS 등)
```

---

## ✨ 주요 기능

### 1️⃣ 진단
- 9개 질문으로 영농 성향 파악
- 특정 작물의 진입 안전성 평가
- 채널별 마진율 비교 분석

### 2️⃣ 계획
- 품목별 초기 투입비용 자동 계산
- KAMIS 실시간 데이터 기반 수익 예측
- 월별 현금흐름 시뮬레이션
- 금융기관 제출용 사업계획서 자동생성

### 3️⃣ 지원
- 청년농업인/선도농인/한농대 특화 지원금
- 농협 대출 상품 안내
- 29개 항목 위험 관리 체크리스트
- 전국 170개 기술센터·농협 연락처

### 4️⃣ 추가 기능
- **PWA**: 모바일 홈 화면에 추가해서 앱처럼 사용
- **오프라인**: Service Worker로 인터넷 없어도 사용 가능
- **실시간 데이터**: KREI·KAMIS·가락시장·통계청 링크
- **SNS 자동화**: Threads 자동 포스팅 시스템

## 🎓 사용 가이드

### 타이밍별 사용법

**현재 (한농대 3학년)**
1. index.html 열기
2. 1단계 진단 3개 도구 모두 사용
3. 관심 작물 3개 선택

**제대 3개월 전**
4. 2단계 계획 3개 도구로 비용·수익 계산
5. 위험 관리 체크리스트 70% 이상 확인

**제대 1개월 전**
6. 3단계 지원 도구로 지원금·연락처 확보
7. 사업계획서 최종 작성

**영농 시작 후**
8. 매달 KAMIS 가격 모니터링
9. 월별 현금흐름 정산

## 🛠️ SNS 자동화 설정 (선택)

이 플랫폼을 SNS에 자동으로 홍보하려면:

1. GitHub Secrets 등록:
   - `THREADS_USER_ID`
   - `THREADS_ACCESS_TOKEN`
   - `HANALL_LINK`

2. GitHub Actions 워크플로우 활성화

자세한 설정은 → `SNS_AUTOMATION_GUIDE.md` 참고

## 🌐 배포 옵션

### GitHub Pages (현재)
- URL: https://kimdo750-ui.github.io/Taehwan/
- 설정: Settings → Pages → Source: main branch
- 비용: 무료
- 장점: GitHub와 통합, 자동 배포

### Vercel (권장)
```bash
# Vercel CLI 설치
npm install -g vercel

# 배포
cd Taehwan
vercel
```
- URL: https://taehwan.vercel.app/
- 비용: 무료
- 장점: 더 빠른 로딩, 자동 HTTPS

### Netlify (대안)
```bash
# Netlify CLI 설치
npm install -g netlify-cli

# 배포
netlify deploy --prod --dir .
```
- URL: 커스텀 가능
- 비용: 무료
- 장점: 간단한 배포
