Threads 연동 상세 가이드

Step 1: Threads API 토큰 획득

Threads는 아직 공식 API가 완전히 개방되지 않았습니다. 다음 중 하나 선택:

  1. Meta for Developers 등록: https://developers.facebook.com → 앱 생성 → Threads API 신청
  2. Instagram API 활용: Instagram 비즈니스 계정 필요 (Threads 계정과 연동)
  3. 수동 포스팅: sns_bot.py에서 자동 생성된 포스트 링크를 사용해 수동 포스팅

Step 2: GitHub Secrets 등록

다음 정보를 GitHub 리포지토리에 저장:

THREADS_USER_ID = 당신의 Threads 사용자 ID
THREADS_ACCESS_TOKEN = Meta API 토큰 (60일 유효)
HANALL_LINK = 홍보할 링크 (예: https://taehwan.vercel.app)
PLATFORM_LINK = 플랫폼 링크

등록 위치: Settings → Secrets and variables → Actions → New repository secret

Step 3: 자동 포스팅 확인

GitHub Actions 탭에서 다음 워크플로우 확인:

  • sns-daily-post.yml: 매일 20:30 KST 자동 실행
  • threads-reply.yml: 3시간마다 '✓' 댓글 자동 응답
⚙️ 콘텐츠 커스터마이징

포스팅 내용 수정

파일: sns-automation/sns_bot.py

CONTENT_TEMPLATES에서 요일별 콘텐츠 수정:

CONTENT_TEMPLATES = {
  "monday": {
    "title": "영농형태 진단",
    "text": "원하는 텍스트 입력",
    "link": "{LINK}"
  },
  # 나머지 요일도 동일하게...
}

포스팅 시간 변경

파일: .github/workflows/sns-daily-post.yml

cron 설정 (UTC 기준, KST = UTC+9):

schedule:
  - cron: "30 11 * * *" # 현재: 매일 20:30 KST

# 다른 시간 예시:
# 19:00 KST = "0 10 * * *"
# 21:00 KST = "0 12 * * *"

파일: sns-automation/config.json

content_strategy.hashtags에서 수정

🔧 문제 해결

❌ "Secrets not found" 에러

원인: GitHub Secrets 미등록

해결:

  1. Settings → Secrets and variables → Actions
  2. 다음 4개 secret 추가:
    • THREADS_USER_ID
    • THREADS_ACCESS_TOKEN
    • HANALL_LINK
    • PLATFORM_LINK

❌ "Token expired" 에러

원인: Threads API 토큰 만료 (60일)

해결:

  1. Meta for Developers에서 새 토큰 생성
  2. GitHub Secrets의 THREADS_ACCESS_TOKEN 업데이트

❌ "Workflow not triggered" 에러

원인: 워크플로우 비활성화 또는 시간 설정 오류

해결:

  1. Actions 탭에서 "I understand my workflows and want to enable them" 클릭
  2. .github/workflows/sns-daily-post.yml의 cron 시간 확인 (UTC 기준)
  3. 수동으로 "Run workflow" 클릭해서 테스트

❌ "Posting failed" 에러

원인: Threads API 연결 실패

해결:

  1. Threads API 인증정보 재확인
  2. Threads 계정이 비즈니스 계정인지 확인
  3. API 권한 설정 확인 (Instagram Graph API)
