## 📋 전체 구조

| 섹션 | 핵심 | 작성 팁 |
|------|------|--------|
| **신청인** | 기본 정보 | 영농시작일은 정확히 (예정일도 OK) |
| **1. 일반현황** | 영농 유형 / 가족 구성 | 농업경영체 등록 전이면 "독립경영" |
| **2. 농지 규모** | 매입/임차 규모 추이 | 현재 확정지와 향후 계획 구분 |
| **3. 소유지** | 구체적 위치 | 리·법·지번까지 정확히 |
| **4. 시설** | 비닐하우스 등 면적 | 5년 후 확장 계획 표시 |
| **5. 농기계** | 보유/구매 계획 | 연차별 단계적 투자 |
| **6. 자금조달** | 자기자금 + 정책자금 | 신정책자금(청년농 대출) 활용 |
| **7. 역량** | 교육 이력 / 자격증 | 한농대 이력 필수 기재 |
| **8-9. 판매·홍보** | 채널별 비중 (%) | 현재 미정하면 향후만 입력 |
| **10. 위험관리** | 장애·위험 요소와 대응 | 병충해, 시장 변동, 자금 부족 등 |
| **11. 교육훈련** | 연차별 계획 | 기술센터 교육, 자격증 과정 등 |
| **12. 동기·계획** | ⭐ 가장 중요 | 3쪽 이내, 스토리텔링 중심 |

## ⭐ 12. 영농동기 및 경영계획 (핵심!)

### 영농 동기

```
【예시】

저는 한국농수산대학을 졸업하며 "지속가능한 로컬 먹거리 생산"이라는 확실한 목표를 얻었습니다. 
도시민들이 "언제 어디서 누가 재배했는가"를 알고 신뢰하는 농산물을 원하는 시대입니다. 
저는 경기도 용인의 비옥한 토지에서 이 니즈를 충족하는 딸기 전문 농업인이 되기로 결심했습니다.

특히 딸기는:
- 계절 상품이 아닌 **통년 판로 가능** (냉동, 가공 등)
- 가족 중심 소규모 재배로 **시작 용이**
- 고부가가치로 **초기 자금 회수 빠름** (1년차 하반기)
- 생산-판매 전 과정을 **내가 관리 가능**

이러한 이유로 딸기 영농을 선택했습니다.
```

### 경영계획 (5개년)

```
【예시】

【1년차: 기초 확립 기간】
- 목표: 안정적인 재배 기술 습득 + 판로 개척
- 농지: 임차 5,000㎡로 시작 (작은 규모로 리스크 최소화)
- 판매: 11월~4월 수확기에 소량 판매 (500kg, 매출 약 3,500만원)
- 투자: 비닐시설 3,000㎡ 렌탈(연 800만원) + 씨앗·비료·영농자재
- 교육: 기술센터 월 2회 + 선배농 멘토링 주 1회
- 성과: 기본 수익률 확보 (순이익 800만원 예상)

【2년차: 확대 단계】
- 목표: 수익성 검증 + 규모 확대
- 농지: 임차 5,000㎡ + 추가 500㎡ (총 5,500㎡)
- 판매: 연 1,200kg, 온라인 입점 추진(마켓컬리 등) → 매출 7,000만원
- 투자: 자동급수 시설 도입(500만원), 냉장고 추가(400만원)
- 기술: GAP인증 추진, 병충해 통합관리(IPM) 심화 교육
- 성과: 순이익 2,000만원 수준

【3년차: 자체 기반 구축】
- 목표: 자가 시설 확보 + 브랜드화
- 농지: 임차 유지 + 매입 3,000㎡ 추진 (대출 1억원, 자기자금 2,000만원)
- 판매: 연 1,800kg, 프리미엄 판로 60% (직거래·온라인·B2B)
  → 매출 1억원 돌파
- 시설: 자가 비닐시설 500㎡ 매입, 냉장·포장실 확대(200㎡)
- 고용: 상시직 1명 + 계절직 3명 채용
- 성과: 순이익 4,000만원, 지속가능 영농 기반 완성

【4~5년차: 안정 + 다각화】
- 목표: 수익 안정화 + 소득원 다각화
- 농지: 임차 5,000㎡ 유지 (매입 추가 검토)
- 판매: 연 2,500kg, 가공 제품(딸기잼·요구르트) 10% 비중
  → 매출 1.3억원
- 새 소득: 양계(유정란) 병행으로 리스크 분산
- 기술: 유기농인증 취득(4년차), 수출 검토(홍콩, 일본)
- 성과: 순이익 6,000만원, 지역 선도 농업인으로 성장

【핵심 성공 요인】
1. 초기 소규모 시작으로 리스크 최소화
2. 기술센터 교육과 선배농 멘토링으로 기술 확보
3. 프리미엄 판로(직거래·온라인) 중심 전략
4. 3년차부터 단계적 시설 투자로 자본효율성 극대화
5. 4년차부터 다각화로 경영 안정성 제고
```

**💡 작성 팁**:
- **구체적 수치** 제시 (생산량, 매출, 순이익)
- **연차별 명확한 목표** 제시
- **투자 계획**과 **수익 계획** 연계
- **교육·기술 개발**을 중요하게 다루기
- **리스크 관리** (소규모 시작, 다각화, 보험) 언급
- 3쪽 이내 (A4 기준) = 약 5,000자
